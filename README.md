
# Inventario de activos IT

Aplicación de consola desarrollada con Python y SQLite para administrar un inventario ficticio de equipos informáticos. Proyecto personal de práctica orientado a reforzar programación, SQL y operaciones habituales de soporte IT.

## Funcionalidades

- Registrar laptops, computadoras de escritorio, monitores e impresoras.
- Buscar equipos por identificador, serie, modelo, ubicación o responsable.
- Actualizar estados y asignaciones.
- Consultar resúmenes de activos por estado.
- Exportar inventarios a CSV compatible con Excel.
- Validar entradas y evitar identificadores duplicados.
- Ejecutar pruebas automatizadas.

## Tecnologías

Python, SQLite, SQL, CSV y unittest.
